# 누적 교훈 (Lessons Learned)

## 이 파일의 용도

각 SPEC 사이클 완료 후 핵심 교훈을 1-3개 항목으로 추가합니다.
**최신 항목이 상단에 옵니다.** 기획자는 새 SPEC 작성 전 최소 최근 5개 항목을 확인합니다.

교훈은 반드시 **패턴 서술 형식**으로 작성합니다:
- ❌ "AC 조건이 모호했다"
- ✅ "외부 API 연동 시 실패 응답 포맷을 AC에 명시해야 한다"
