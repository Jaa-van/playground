# Inbox — 기획 메모함

> 새 기능 아이디어를 여기에 작성하면 Planner가 SPEC으로 변환합니다.

## 사용 방법

1. `_template.md`를 복사해서 새 파일 생성
2. 파일명: `[기능-이름].md` (예: `user-login.md`)
3. 내용 작성 후 저장
4. Planner 세션 시작 시 자동으로 읽어서 처리

## 작성 팁

- 기술 용어 없이 **사용자 관점**으로 작성
- "반드시 포함" 항목을 명확히 할수록 SPEC 품질이 올라감
- 복잡하면 기능을 쪼개서 여러 파일로 작성
